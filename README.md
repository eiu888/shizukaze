Shizukazeは、明確で意図的なワークフローを通じてLINEアカウントの削除を処理するための焦点を絞ったデスクトップツールです。

## 使用シーン

一部のアカウントはオンラインに残すべきではありません。

| 状況 | Shizukazeを使う理由 |
|------|---------------------|
| **アカウントが侵害された** | アカウントの管理権限を失った場合、オンラインのままにしておくと被害が続く可能性があります |
| **しつこいスパム** | ブロックだけでは根源を止められない場合、より決定的な対応が必要です |
| **なりすまし** | 偽のアイデンティティは混乱を広げます。偽アカウントがさらに広がる前に行動してください |
| **決着が必要な場合** | ミュート、ブロック、無視では不十分な状況もあります |

## 使用方法

1つの対象。1つの決断。

1. **インストール** — Windows用をダウンロードし、デスクトップアプリケーションを開きます
2. **対象を入力** — LINE ID、プロフィールリンク、または対応する番号を選択して入力します
3. **プロセスを実行** — リクエストを開始し、完了するまで各段階を追跡します

## 機能

- **3種類の対象形式** — LINE ID、プロフィールリンク、対応番号
- **1つの焦点を絞ったワークフロー** — 各画面は明確な目的を持ちます
- **匿名性** — リクエストはデータセンターを経由する前に匿名化されます
- **デスクトップ専用** — Windows 10/11対応（モバイル版は開発中）
